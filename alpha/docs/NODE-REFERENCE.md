# Fiona Zi Engine - Node Reference

Generated by `FZEVSNodeReference` from the engine's node registry - the same list the
Visual Script palette shows. 411 nodes in 24 categories.

- **Type** is what is saved in a graph; the palette shows the **Title**. Search the palette
  (right-click the canvas, or drag a wire into empty space) by either.
- **Kind**: *event* starts a flow; *action* has white execution pins; *value* (pure) has none
  and is worked out when something reads it; *flow* steers execution.
- Every `call.<Class>.<Name>` node is also a C# method of the same name - `call.Entity.SetPosition`
  is `entity.SetPosition(...)`, `call.Audio.PlaySound` is `Audio.PlaySound(...)`. An action on
  an object has a **Target** pin (empty = the object the graph is on; `Entity` in C#).
