Open Asset Import Library (Assimp)  -  wide-format model import
https://github.com/assimp/assimp
Copyright (c) 2006-2026, assimp team. All rights reserved.
Licensed under the 3-clause BSD licence: vendor/assimp/LICENSE

Vendored as a static library and used as the engine's wide-format
model import front end (OBJ, Collada, 3DS, PLY, STL, X, MD5, LWO,
BLEND and others). Exporters are compiled out (ASSIMP_NO_EXPORT).
glTF and FBX are NOT routed through Assimp; they keep the tinygltf
and ufbx backends below. Assimp's contrib/ directory bundles the
parsers it depends on (zlib, pugixml, rapidjson, utf8cpp, poly2tri,
clipper, openddlparser, unzip, stb) under their own permissive
licences; each carries its notice inside vendor/assimp/contrib/.

Google Filament  -  material model (shader mathematics only)
https://github.com/google/filament
Copyright (C) 2017 The Android Open Source Project
Licensed under the Apache License, Version 2.0.

Shaders/lib/Material.glsl derives its BRDF from Filament's shader
sources (shaders/src/surface_brdf.fs, surface_shading_model_standard.fs,
surface_shading_lit.fs): the height-correlated Smith visibility term,
the Burley diffuse term, the reflectance-to-F0 mapping and the
multiple-scattering energy compensation. No Filament code, binaries or
build system are linked; what was taken is the material MODEL,
reimplemented against this engine's own uniforms and its own split-sum
BRDF table. This notice is kept because the Apache licence asks for
it on derived work. Full licence text: https://www.apache.org/licenses/LICENSE-2.0

====================================================================
NOT DISTRIBUTED, BUT USED
====================================================================

- The editor loads Segoe UI from the Windows fonts folder at run
  time (Engine/Editor/EditorUI.cpp). The font is not redistributed.

- The installer (installer/FZE.iss) is built with Inno Setup and
  bundles the Microsoft Visual C++ Redistributable (vc_redist.x64.exe),
  which Microsoft licenses for redistribution with applications built
  with Visual Studio. Neither tool is part of the engine.

- vendor/godot-import/ (Godot Engine sources, MIT) is a reference
  copy kept on the Author's machine for reading. It is not tracked
  in the repository and nothing in the engine compiles or includes
  it.
